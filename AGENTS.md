# Agent Notes

* Use `uv` for Python commands.
* Keep commits scoped; do not stage unrelated local changes.
* When a commit fixes a GitHub issue, include `Fixes #N` in the commit body.
* Credit agent-authored commits with that agent's own `Co-authored-by` trailer.
* Run the smallest focused check that covers the change.
* Build macOS releases with `./release-mac.sh`.
